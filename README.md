# Lyxvo.ai Bot

The official bot of **[Lyxvo.ai](https://lyxvo.ai)**, the AI website and app builder by Lyxvo (Indonesia).

When you connect GitHub in Lyxvo.ai (Account → GitHub → *Continue with GitHub*) and install the **Lyxvo.ai** GitHub App, this bot works in the repositories you choose:

- **Push your website's code** from Lyxvo Build to a new or existing repository, as a ready-to-run Vite app.
- **Commit and open pull requests** when you ask Lyxvo Agentic to change files in a repository.
- **Back up your own servers**: code and, when you ask, database dumps go to a private repository.
- **Build apps with GitHub Actions**: Lyxvo Agentic can write the workflow, run it and give you the build files.

Commits and pull requests made by the bot appear as `lyxvo-ai[bot]`.

## Your control

- You choose which repositories the app can use, and you can change or remove it any time in GitHub → Settings → Applications.
- Lyxvo writes to GitHub only when you push, approve a change, or ask for it in Build.
